# Aula: Painel Inteligente

Site interativo da aula de fórmulas nos painéis (Google Sheets).
O aluno informa o nome ao entrar; o progresso da missão e o resultado do quiz são registrados na aba **Registro do Desafio** da planilha da turma, por meio do Apps Script em `apps-script/`.

Aviso: a API é pública e grava apenas o nome do aluno e o progresso da aula.
